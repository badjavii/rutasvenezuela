## Sobre el módulo

El **frontend** contendrá la interfaz web de RutasVenezuela.

Su propósito será proporcionar los componentes visuales, formularios y mecanismos de navegación necesarios para interactuar con las funcionalidades de la aplicación.

## Arquitectura

El framework y la estructura de componentes están pendientes de selección.

Este directorio estará destinado al código de la interfaz, los recursos visuales y los archivos de configuración correspondientes.

## Instalación

Las instrucciones de instalación se incorporarán una vez seleccionado el framework.

## Uso

La interfaz todavía no dispone de una implementación ejecutable.

## Notas

- La interfaz debe mantenerse separada de la lógica de negocio del servidor.
- No deben exponerse credenciales privadas en el código del cliente.
- Los componentes reutilizables seguirán convenciones de nombres consistentes.
- La navegación y las interacciones se documentarán durante el desarrollo.

## Créditos

Módulo perteneciente al proyecto **RutasVenezuela**, desarrollado para la asignatura Sistemas de Bases de Datos de la UCAB.
