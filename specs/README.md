# Especificaciones del proyecto

SDD basado en las plantillas de la asignatura de APIs de Python. No requiere OpenSpec ni extensiones específicas de OpenCode.

El [documento de constitución](constitution.md) define las reglas de trabajo. Cada capacidad contiene `spec.md`, `plan.md` y `tasks.md`; la carpeta `templates/` contiene las plantillas reutilizables.

- `territory-heritage/`: capacidades de Javier.
- `mobility-routes/`: capacidades de Sebastián.
- `actors-commerce/`: capacidades de Valeria.
